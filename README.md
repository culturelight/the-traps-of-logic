# 邏輯的陷阱 · The Traps of Logic

**識別謬誤，看清論點。作者：許啟業（Brandon Hui / B Hui）。**

一本面向一般讀者的繁體中文書稿，從日常對話、歷史故事與反思練習，探索容易讓人誤判的推理方式。全書以七個部分、44 章，討論情感與權威、論證結構、證據與概率、過度簡化、因果、針對人的攻擊，以及辯論中的話術。

## 試讀內容

本試讀包括封面、試讀說明、章節插圖，以及完整的「人身攻擊：針對人 ≠ 針對觀點」章節。正文節錄自校訂稿，為分享重新排版，保留原文。

內容包含日常例子、謬誤定義、歷史故事、識別方法、反思練習與回應方式。

## English overview

*The Traps of Logic* is a Traditional Chinese book project exploring reasoning mistakes through everyday examples, historical stories, and practical reflection. This six-page manuscript preview includes the cover, an introduction, a chapter illustration, and the complete chapter on ad hominem arguments. The chapter text is preserved and newly typeset for this sample.

Publication on Lulu.com is planned for **November 2026**, according to the author.
